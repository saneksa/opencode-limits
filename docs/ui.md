# Пользовательский интерфейс

Приложение работает как меню-барное: в `Info.plist` задано `LSUIElement = true`, поэтому значка в Dock нет. Дополнительно `AppDelegate` устанавливает политику активации `.accessory`. Единственный постоянный элемент интерфейса — иконка в строке меню, создаваемая вручную через `NSStatusItem` (не через SwiftUI `MenuBarExtra`), чтобы надёжно различать левый и правый клик.

См. также: [Архитектура](architecture.md), [Источники данных](data-sources.md), [Настройки](configuration.md), [Сборка и тесты](build-and-test.md), [Безопасность](security.md), [README](../README.md), [Журнал разработки](development-log.md).

## Иконка в строке меню

Реализация: `Sources/OpenCodeLimits/Views/TrayIcon.swift`. Изображение рисуется кодом, размер **22×22 pt при @2x (44×44 px)**, `isTemplate = false`.

- **Единственное кольцо** (радиус 8.6, толщина 2.2) показывает **убывающую дугу времени до сброса 5-часового окна**: полный круг = осталось 5 часов, пустой = сброс уже сейчас. Значение берётся из `countdown.rollingWindowFraction(now:)`, где `countdown` — всегда `usage.rolling`, независимо от выбранного лимита. За дугой рисуется бледно-серый «трек»; если `resetsAt` или доля неизвестны, остаётся только трек.
- **Цвет кольца — зелёный** (`systemGreen`). Исключение: если выбранный лимит `isRateLimited`, кольцо становится красным, чтобы заблокированный лимит был заметен. Оранжевый и порог `warnThreshold` для иконки больше не используются.
- **Цифры по центру** — процент **выбранного** лимита (`meter.percent`), белым цветом поверх кольца. Жирный шрифт 8.0 pt для одной цифры, 7.2 для двух, 5.8 для трёх и 6.2 для большего числа. Если данных нет — нейтральный серый символ «–».

Внутреннего кольца, синего/бирюзового прогресса и переключателя отображения больше нет.

## Выбор лимита для иконки

`TrayMeter`: `rolling`, `weekly`, `monthly`, `auto`. По умолчанию — **`rolling`**. Режим `auto` использует `UsageSnapshot.worst` (максимальный процент; при равенстве приоритет у rate-limited).

Настройка влияет **только на иконку**. В окне всегда видны все три карточки, и уведомления также охватывают все три лимита.

## Левый и правый клик

Владелец статус-элемента — `Sources/OpenCodeLimits/App/StatusBarController.swift`:

- `button.sendAction(on: [.leftMouseUp, .rightMouseUp])`;
- обработчик проверяет `NSApp.currentEvent?.type == .rightMouseUp`.

**Левый клик** открывает transient `NSPopover` с `NSHostingController(rootView: MenuBarView().environmentObject(state).environmentObject(state.settings))`, `preferredEdge: .minY`, с вызовом `NSApp.activate(ignoringOtherApps: true)`. Повторный клик закрывает поповер.

**Правый клик** показывает `NSMenu`:

1. «Открыть» — открыть тот же поповер;
2. «Настройки…» — `SettingsWindowController.shared.show(state:)`;
3. разделитель;
4. «Выход» — `NSApp.terminate(nil)`.

Меню всплывает через `menu.popUp(positioning: nil, at: NSEvent.mouseLocation, in: nil)`. Свойство `statusItem.menu` **никогда не устанавливается**, иначе левый клик открывал бы меню вместо поповера.

Иконка перерисовывается по подпискам Combine на `state.$clock`, `$trayMeter` и `$trayCountdownMeter`. Эти подписки не запускают сетевой запрос.

## Окно «Лимиты»

`MenuBarView` содержит заголовок «OpenCode Go» с индикатором состояния, живую подпись «Обновлено N сек назад», баннер ошибки с кнопкой «Повторить», три карточки `UsageMeterView` и сегментированный переключатель «Лимиты» / «Активность».

Карточка показывает процент, капсульную шкалу, бейдж «Лимит исчерпан» для `rate-limited`, живой обратный отсчёт до сброса и локальную дату сброса. Снизу — примечание о правилах сброса (5 ч — 20 % месячного лимита, окно стартует с первого запроса; неделя — 50 %, сброс понедельник 00:00 UTC). Кнопки: «Обновить», «Настройки», «Выход».

## Окно «Активность»

`ActivityView` (`import Charts`):

- **Период**: 7 дней, 30 дней, 90 дней, «Всё время» (значение 0). Для конечного периода берётся `activity.daily.suffix(period)` и столбцы с единицей `.day`; для «Всё время» — `activity.monthly` и единица `.month`.
- **Метрика**: «Токены» или `$`; переключатель работает в обоих режимах периода.
- **Плитки**: всего токенов, стоимость, «Шагов» (если `source == .api`, где `totalMessages` содержит agent steps) либо «Сообщений», а также дней/месяцев с активностью.
- Подпись «Источник: API OpenCode» или «Источник: Локальная БД», до 12 последних сессий и топ-6 моделей с долями-полосками. Пустое состояние отображается, если событий нет. Содержимое переписки не показывается никогда.

## Окно настроек

`SettingsWindowController` создаёт окно **явно** через `NSWindow(contentRect: 600×700, …)`, задаёт `NSHostingController.preferredContentSize`, `minSize = 520×460`, `maxSize = 900×1100`, `isReleasedWhenClosed = false`. Вёрстка — `ScrollView(.vertical) { VStack { … } }` **без `Form`**: macOS `Form` имеет собственную минимальную ширину и обрезался по бокам даже при 480 pt. Каждая строка использует фиксированную колонку подписей 170 pt, а элементы занимают остаток; все описательные подписи используют `.fixedSize(horizontal: false, vertical: true)` и переносятся, а не обрезаются многоточием.

Разделы формы:

- **«Обновление»** — интервал опроса 30/60/300 с, выбор лимита в строке меню, подпись «Кольцо показывает время до сброса 5-часового окна, цифра — выбранный лимит.», шаг порога предупреждения 0…100 с шагом 5.
- **«Энергосбережение»** — переключатель экономии, интервал от батареи 1/5/15 мин, живая подпись о типе питания и текущем интервале опроса, примечание о Low Power Mode, снижении частоты обновлений и паузе таймеров во сне.
- **«Ключ доступа Go»** — выбор источника, активный источник, `SecureField` + кнопки «Сохранить в Keychain» / «Удалить», кнопка «Проверить соединение».
- **«Запуск»** — включение запуска при входе в систему.
- **«Конфиденциальность»** — короткая заметка: ключ не логируется, БД только для чтения, содержимое переписки не читается.

Подробности — в [Настройках](configuration.md).

## Состояние и обновления

`AppState` (`@MainActor`, `ObservableObject`) публикует `usage`, `activity`, `errorMessage`, `isRefreshing`, `lastUpdated`, `trayMeter`, `trayCountdownMeter`, `clock`, `powerState`, `effectivePollInterval`.

Таймер `clock` работает каждые **30 с** в обычном режиме и **60 с** в энергосберегающем — это чисто визуальный тик, без сетевых запросов; он заставляет дугу отката плавно укорачиваться между опросами сети. Таймер опроса использует `effectivePollInterval`. Активность перезагружается не чаще раза в **5 мин** (15 мин в энергосберегающем режиме); кнопка «Обновить» и смена периода делают запрос явно. `NSWorkspace.willSleepNotification` вызывает `suspendForSleep()`, `didWakeNotification` — `resumeFromWake()` и `refresh(requestActivity: true)`.

## Уведомления

`UNUserNotificationCenter` показывает не более одного уведомления на лимит в одном окне; смена `resetsAt` взводит лимит снова. Если разрешение не выдано или у бинарника нет bundle identifier (обычный `swift run`), используется `NSSound.beep()`. Подробнее — [Безопасность](security.md).

## Ограничение: SwiftUI-макросы

В интерфейсе **не используются** `@State`, `@AppStorage`, `#Preview`, `@Observable` и `@Environment(\.openSettings)`. Плагин `SwiftUIMacros` отсутствует в CommandLineTools, поэтому эти макросы не компилируются. Вместо них применяются `@StateObject`, `ObservableObject` и `Binding`. Окно настроек создаётся через AppKit, так как `openSettings` доступен только с macOS 14.
